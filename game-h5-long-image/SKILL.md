# 静态游戏 H5 长图

以手机阅读为目标。先确定布局和真实内容，再制作所需素材，最后融合整页。先读 [布局](references/layout.md)，制作素材时读 [素材制作](references/materials.md)，制作整页和交付时读 [整页融合与交付](references/final-page.md)。

## 先定内容和参考职责

- 从实际需求提取活动用途、目标宽度、完整文案、角色和必需模块。分别写清身份素材、画风参考和版式参考。
- 保留用户指定的角色、Logo、活动原文和先后顺序。未给出的日期、价格、奖励数量、概率和玩法承诺留待确认。
- 用户要求方案或预览时交付布局样图、素材计划和可复制的提示词，等待下一步指示。根据明确制作需求和宿主支持的能力推进制作。

## 1. 布局样图

写出首屏、各模块顺序、相对高度、标题与正文的位置，以及每张已有素材的位置。按目标手机阅读宽度安排可读字号、行距和间距。缺少素材时用简单形状标注位置，制作备注写在样图外侧。

列出每个部件的位置、来源和制作方式。优先复用可用首图和准确标题。按是否需要新做首图、独立主标题、组图与整页分别说明出图数量，裁切和本地排布单列。

## 2. 准备独立素材

工作流使用 GPT Image 2.5 制作缺少的首图、透明主艺术字、章节字组和模块装饰。复杂艺术字或多元素组图可选 Sunburst，实际选项按当前可用模型决定。

主标题独立制作，需要透明的前景保留真实 Alpha。相同用途的部件可组织成一张素材组图，留出安全裁切间距。先查看实际生成图，再按内容边界裁切，保留原素材组和各裁片与章节的对应关系。

## 3. 整页融合

工作流使用 Nano 2.1 统一背景、章节衔接、色光与纹理。参考优先使用已确认的正式素材，每张参考写清角色、标题或章节职责。按目标尺寸检查图像模型的实际画幅与参考图输入限制。

在整页提示词里写出首屏焦点、模块顺序、正文与按钮的位置、需要保留的字形和文案，以及章节如何自然衔接。布局样图用于确定阅读顺序与位置，整页参考使用确认的真实部件。需要位置参考时，用确认部件做一张干净的合成图。

## 4. 复核与交付

确认真实结果后，从全页和手机阅读尺度检查角色、准确文字、模块顺序、留白、边缘与过渡。识别具体修改位置和必须保留的部分。

交付已保存的整张静态长图、真实的素材组与裁切文件，以及基于成图的修改建议。记录可独立复用的部件。制作工具不足时交付已完成的布局、素材清单和制作指令。
