# 素材制作与分组

## 独立资产

按已定版式选择需要新做的部件。工作流使用 GPT Image 2.5 准备首图、独立主标题、小标题和模块装饰。较复杂的艺术字或同类组图可选 Sunburst。已适用的首图、品牌标识和字组直接复用。

主艺术字只包含准确文字和依附其上的装饰。需要透明的素材检查实际 Alpha、字腔、边缘和局部光效。不要把普通背景或展示框留在透明图里。

## 同类素材组

同一字号的小标题、同一类承托或同一类装饰分别成组。提示词写清每件的文字或形状、摆放顺序、像素需求、留边和透明要求。部件留足分离距离，发丝、阴影、飘带和光晕进各自的安全范围。

查看真实组图后按像素边界裁切。保存源组图和每个裁片，用可读名称记录是哪一节使用。纯裁切、排列和合成走本地图像工具。

## 给整页的参考

按所用模型真实输入限制选图。让首图或关键角色、主标题有足够面积。章节小标题与装饰可按同类整合，逐部件注明位置与职责。需要位置锚点时，使用正式素材制作干净的合成参考图。
