# 手机长图布局

## 内容表

逐段记录必需章节、准确文字、图片与按钮、作用、顺序和相对高度。按用户提供的活动内容组织首屏、介绍、规则、奖励或操作引导。根据真实内容决定章节数量和页面长度。

按手机宽度检查阅读顺序和字号。关键文字留在低纹理区域，跨模块延续相同的字重和边距。较长的正文用独立段落排版，规则密集时先组织小标题和段距。

## 素材来源

每张参考说明承担的职责。身份素材用于保留角色、服装、品牌或准确文字。风格参考用于光影、笔触、材质和配色。版式参考用于区块位置、比例和阅读顺序。

把真实可用的素材放进布局样图。需要新做的标题、承托和装饰用形状写明位置，在旁边列出用途和制作方式。已有合适的首屏主视觉可以直接复用。

## 布局交付

提供页面宽度、章节顺序、各区主要文字、图文位置和素材清单。说明哪些素材直接使用，哪些独立生成，哪些同组制作后裁切，哪些由整页融合阶段完成。将制作备注留在方案说明区。

比较备选版式时，使用同一份必需内容，分别说明首屏焦点、阅读动线和真实素材差异。
